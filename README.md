# GitHub Actions SVID demo

Generated by a local demo script, which also deletes it. Don't edit it by hand.

Each workflow runs `get-svid.mjs`, which uses the job's GitHub OIDC token to request
a SPIFFE SVID from Defakto. The repo holds no secrets. The only config is the
`DEFAKTO_TRUST_DOMAIN_ID` repo variable.

| Workflow | Trigger | Expected |
|---|---|---|
| `get-svid.yml` | manual run on `main` | SVID issued |
| `get-svid.yml` | pull request | denied (not `main`) |
| `rogue.yml` | manual run | denied (workflow not in policy) |
| `deploy.yml` → `production` | manual run + reviewer approval | SVID issued after approval |
| `deploy.yml` → `staging` | manual run | denied (environment not in policy) |
